# 安全与免责

远程 MCP 使用独立 `MCP_AUTH_TOKEN`；`ONE_EARBUD_TOKEN` 继续用于手机 Web/API，两者不能相同。ChatGPT 通过官方 SDK OAuth 授权后使用独立 Bearer 令牌，不能取得网易云 cookie。网易云登录态可选外部加密存储；未启用时与 OAuth 私密文件一样存在 `ONE_EARBUD_DATA_DIR`。公网部署必须配置网页口令，MCP 未配置口令时关闭。完整步骤见 [MCP.md](MCP.md)。

ChatGPT 内嵌卡片的资源读取和控件调用继续使用同一 OAuth/Bearer 保护；卡片本身不取得两个环境变量口令或网易云 cookie。`app` 工具可见性不代替服务端鉴权。新增用户按钮只允许暂停、恢复及前后切歌，并校验新鲜歌曲预期值、短期指令和幂等键；不授予清空、删除、挪动、登录或导入权限。CSP/消息来源/图片 URL 校验和降级说明见 [MCP-UI.md](MCP-UI.md)。

V2.6 另外允许用户在卡片浏览**当前账号**歌单、搜索和明确点歌。只读 app 工具不接受任意账号 UID，不返回账号资料或 Cookie；点歌使用当前 stream/epoch 和播放会话校验，按用户操作记入原队列，并用 requestId 去重。它不提供编辑网易云歌单、清空队列、整份导入或登录管理权限。音乐工具原有权限与 OAuth scope 保持不变。

## 登录信息存在哪

V2 的播放端交接只使用内存中的 epoch/会话/序号/trackId，不改网易云或 OAuth 存储。卡片取得的音频能力地址仅在工具 `_meta` 中传递，限定当前播放会话与歌曲，10 分钟过期；不包含现有网页/MCP 口令或网易云 Cookie。`/widget-media` 不是普通公开代理：只能转发已由后端解析并通过域名/HTTPS 验证的网易云地址，支持 Range，不转发调用者鉴权头或上游 Set-Cookie。不要分享能力地址。详见 [MCP-UI.md](MCP-UI.md)。

- 网易云登录态：默认服务器 `ONE_EARBUD_DATA_DIR/netease-auth.json`，文件权限 0600，原子写入。
- Render Free 推荐设置 `ONE_EARBUD_AUTH_DATABASE_URL` 和独立的 `ONE_EARBUD_AUTH_ENCRYPTION_KEY`：Cookie/账号资料以 AES-256-GCM 保存到 PostgreSQL 表 `one_earbud_netease_auth`，强制验证数据库 TLS 证书；数据库连接串和加密密钥仅存在 Render 环境变量，不提交仓库。启动完成恢复后才监听端口；配置失败不回退、不清空登录。迁移成功后删除原明文文件。队列存储不变。
- OAuth 使用同一对已有数据库/加密变量，独立加密保存到 `one_earbud_oauth_state`（与网易云使用不同 AAD）。动态注册、进行中的授权、授权码和 token 哈希均持久化，不在普通重启时消失。事务行锁保证并发更新和刷新令牌单次消费；1 小时 access TTL、30 天轮换 refresh TTL、PKCE、客户端/受众约束均保留。缺少数据库配置才沿用本地私密文件。数据库故障不回退临时状态、不删除已有授权。诊断日志只输出固定原因码，绝不输出客户端 ID、请求参数、授权码或令牌。
- 它**不会**通过任何读接口返回，也不会写进日志。`/api/music/status` 只返回昵称、是否会员。
- 访问口令：`.env` 的 `ONE_EARBUD_TOKEN`。没设口令时，任何能访问你服务器的人都能用你的网易云登录态——只在本机试用时这么做。

## 绝不能提交到仓库的

- `.env`
- `.env.*`（只有不含真实密钥的 `.env.example` 可提交）
- 任何位置的 `netease-auth.json`、`oauth-state.json` 及其临时文件
- `data/` 整个目录（登录态、播放列表）
- 你自己的域名、服务器地址、网易云账号 id、任何密钥

`.gitignore` 已经写好前两项；后两项请在提交前自己 `grep` 一遍。

## TA 的权限边界

- TA 能读 YOU 正在听什么、读歌词、搜歌、发歌卡、往列表里加歌、直接放一首。
- TA 不能删歌、挪顺序、换模式、清空列表、导入歌单、登录或退出网易云。
- 「正在听」只在内存里，服务器重启就没了；不做历史记录。想做历史，请先征得 YOU 同意。
